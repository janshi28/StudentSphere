# StudentSphere — A Serverless Student Career Portal

A fully serverless web application for student career profile management built on AWS.

## About
StudentSphere allows students to create academic profiles, view a Career Readiness Score, and download a resume. Admins can view, edit, delete and export all student records.

## AWS Services Used
- Amazon S3 — Frontend hosting
- Amazon Cognito — User authentication
- API Gateway — REST API
- AWS Lambda — Backend (Python)
- DynamoDB — Database

## Features
- Student login via Amazon Cognito
- Career Readiness Score (GPA + Skills + Certifications + Projects)
- One-click Resume Download
- Admin Panel with search, edit, delete, CSV export
